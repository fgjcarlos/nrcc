# Operator playbook

> **Stub.** Landed as a skeleton in W1. Task-oriented guides
> (upgrade, certificate rotation, backup, recovery, dashboard
> access) arrive in W6.

## Tasks

1. Upgrade NRCC.
2. Rotate `credentialSecret`.
3. Rotate HTTPS certificates.
4. Restore from a backup.
5. Enable / disable Dashboard.
6. Recover from a failed apply.
7. Recover from a forgotten admin password.

Each task lands with a "Verify" block in W6.
